# Projeto Cadastro de Paciente.

## Este é um exercicio proposto pelo professor Felipe, para exercitar nosso conhecimento em Python e biblioteca TKinter, este exercicio foi baseado em um exercicio feito em sala junto com o professor.
## Criar um formulário de cadastro de paciente utilizando Tkinter. 

Requisitos do Sistema
O sistema deve ter DUAS ABAS:

Aba 1 – Cadastro do Paciente
Campos obrigatórios:
Nome completo
CPF
Data de nascimento
Telefone
Email
Convênio/SUS
Contato de emergência

Aba 2 – Pacientes Cadastrados
Deve exibir os dados em formato de tabela (Treeview)

O Exercio foi concluido no mesmo dia que foi proposto.
